# 加油站充电服务台账 · 班次交接

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

在原班次交接页上扩展的充电服务台账，数据保存在浏览器 localStorage 中，重开页面可接着处理未结订单与待修设备。

## 业务规则

- **车辆进场**：登记车牌、电话并绑定枪号与车位。同一把枪上前一单未「确认拔枪并结清」时，后车自动进入候位区，订单写明卡点。
- **拔枪 / 结清分离**：拔枪只进入「已拔枪待结清」，枪位仍被占用；收款结清后才释放枪位，候位车方可安排上桩。
- **设备报修**：报修后该枪关联车位立即停用（占用判定实时生效，不改设备资料）；维修先登记为「修复待确认」，确认前不能恢复接单。
- **交接班**：发起时冻结在场车辆、未结订单、待修设备快照，接班人逐辆逐项核对勾选；未确认前责任仍留在原班，也可驳回由原班处理后重新发起。

## 代码结构

- `src/charging/types.ts`：订单、设备、维修工单、交接单领域类型
- `src/charging/domain.ts`：占用判定、卡点、可用枪位等纯函数规则
- `src/charging/storage.ts`：本机保存与种子数据（与页面渲染分离）
- `src/charging/store.ts`：Pinia 状态中心，收口全部状态流转
- `src/charging/*Panel.vue` / `StallBoard.vue`：枪位看板、订单台账、设备维修、交接班四个页面
